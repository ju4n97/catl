# Embedding in Go

The `catl` Go module provides programmatic read access to catalogs and multi-catalog registries. It contains no CGO dependencies, uses no background threads, and executes validation offline.

Install the module:

```bash
go get github.com/ju4n97/catl@latest
```

```go
import "github.com/ju4n97/catl"
```

## Opening a catalog

Use `catl.Open` to read and validate a catalog from disk:

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/ju4n97/catl"
)

type Policy struct {
	Severity string `json:"severity"`
	Enabled  bool   `json:"enabled"`
}

func main() {
	ctx := context.Background()

	cat, err := catl.Open(ctx, "./compliance-catalog")
	if err != nil {
		log.Fatalf("failed to open catalog: %v", err)
	}

	// Resolve an entity by collection and qualified ID ("namespace.id")
	entity, err := cat.Resolve("policies", "compliance.require-mfa")
	if err != nil {
		log.Fatalf("failed to resolve entity: %v", err)
	}

	// Decode the manifest into your struct
	var p Policy
	if err := entity.Unmarshal(&p); err != nil {
		log.Fatalf("manifest decode error: %v", err)
	}

	fmt.Printf("Policy %s: severity=%s enabled=%v\n", entity.QualifiedID, p.Severity, p.Enabled)
}
```

`catl.Open` executes these steps during boot:

1. Parses and validates `catl.toml`.
2. Verifies `catl.lock` freshness if dependencies are declared.
3. Resolves direct dependencies from local paths, `.catl/vendor`, or the global cache.
4. Validates all manifests against their collection JSON Schemas.
5. Returns an immutable `*catl.Catalog` safe for concurrent use across goroutines.

## Verifying tree hashes

To verify catalog content integrity or check for drift, compute the deterministic SHA-256 tree hash:

```go
treeHash, err := cat.TreeHash()
if err != nil {
	log.Fatalf("tree hash computation failed: %v", err)
}
fmt.Println("Catalog SHA-256 tree hash:", treeHash)
```

## Reading companion files

For bundle entities, access companion files using `entity.FS(ctx)`:

```go
package main

import (
	"context"
	"fmt"
	"io/fs"
	"log"

	"github.com/ju4n97/catl"
)

func readRunbook(ctx context.Context, cat *catl.Catalog, qualifiedID string) error {
	entity, err := cat.Resolve("monitors", qualifiedID)
	if err != nil {
		return err
	}

	if !entity.IsBundle() {
		return fmt.Errorf("entity %q is a flat entity and has no companion files", entity.ID)
	}

	// Returns an io/fs.FS scoped to the bundle directory
	bundleFS, err := entity.FS(ctx)
	if err != nil {
		return err
	}

	data, err := fs.ReadFile(bundleFS, "mitigation.md")
	if err != nil {
		return fmt.Errorf("could not read companion file: %w", err)
	}

	fmt.Println(string(data))
	return nil
}
```

The returned filesystem follows standard Go `fs.ValidPath` rules: paths escaping the bundle directory with `..` are rejected, and dot-prefixed files are hidden.

## Working with registries

When an application manages multiple independent catalogs concurrently (such as customer tenants or isolated environments), use `catl.OpenRegistry`:

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/ju4n97/catl"
)

func main() {
	ctx := context.Background()

	reg, err := catl.OpenRegistry(ctx, "./registry.d")
	if err != nil {
		log.Fatalf("failed to open registry: %v", err)
	}

	// List discovered catalog namespaces
	for _, name := range reg.Names() {
		cat, _ := reg.Catalog(name)
		fmt.Printf("Catalog: %s (%d collections)\n", cat.Name(), len(cat.Collections()))
	}

	// Query an entity directly within a specific tenant catalog
	compliance, ok := reg.Catalog("compliance")
	if ok {
		ent, err := compliance.Resolve("rules", "compliance.require-mfa")
		if err == nil {
			fmt.Println("Resolved entity path:", ent.ManifestPath)
		}
	}
}
```

## In-memory testing with OpenFS

To test catalogs without touching the disk, pass a `testing/fstest.MapFS` or Go's standard `embed.FS` to `catl.OpenFS`:

```go
package main

import (
	"context"
	"embed"
	"io/fs"
	"testing"

	"github.com/ju4n97/catl"
)

//go:embed testdata/catalog/*
var testCatalogFS embed.FS

func TestCatalogIntegration(t *testing.T) {
	ctx := context.Background()

	subFS, err := fs.Sub(testCatalogFS, "testdata/catalog")
	if err != nil {
		t.Fatalf("sub fs error: %v", err)
	}

	cat, err := catl.OpenFS(ctx, subFS)
	if err != nil {
		t.Fatalf("OpenFS failed: %v", err)
	}

	entity, err := cat.Resolve("rules", "test-catalog.allow-all")
	if err != nil {
		t.Fatalf("Resolve failed: %v", err)
	}

	if entity.ID != "allow-all" {
		t.Errorf("got ID %q, want allow-all", entity.ID)
	}
}
```

## Atomic swapping in servers

Long-running services can reload catalogs on disk without restarting by using `sync/atomic`:

```go
package main

import (
	"context"
	"sync/atomic"

	"github.com/ju4n97/catl"
)

type Server struct {
	catalog atomic.Pointer[catl.Catalog]
}

func (s *Server) Reload(ctx context.Context, dir string) error {
	next, err := catl.Open(ctx, dir)
	if err != nil {
		return err // Validation failed; keep current catalog active
	}

	s.catalog.Store(next)
	return nil
}

func (s *Server) CurrentCatalog() *catl.Catalog {
	return s.catalog.Load()
}
```

## Error handling

Inspect failure reasons using standard `errors.Is`:

```go
if err != nil {
	switch {
	case errors.Is(err, catl.ErrNotFound):
		// Entity, collection, or catalog namespace does not exist
	case errors.Is(err, catl.ErrNotQualified):
		// Caller passed a bare ID without a namespace ("id" instead of "namespace.id")
	case errors.Is(err, catl.ErrLockStale):
		// catl.lock is missing or out of sync with catl.toml; run 'catl update'
	case errors.Is(err, catl.ErrTamperedVendor):
		// Files inside .catl/vendor do not match the recorded tree hash
	case errors.Is(err, catl.ErrCRLFForbidden):
		// Structured file contains CRLF line endings instead of LF
	case errors.Is(err, catl.ErrRequiresNewer):
		// catl.toml requires a newer version of the catl tool
	}
}
```

To inspect line-by-line schema validation failures, extract `*catl.ValidationError` using `errors.As`:

```go
var valErr *catl.ValidationError
if errors.As(err, &valErr) {
	for _, d := range valErr.Diagnostics {
		log.Printf("%s:%d: [%s] %s\n", d.Path, d.Line, d.Pointer, d.Message)
	}
}
```
