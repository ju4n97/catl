# Embedding in Go

The `catl` Go module provides programmatic read access to catalogs and multi-catalog registries. It contains no CGO dependencies, uses no background threads, and executes validation offline.

Complete type signatures, interfaces, and methods are maintained in GoDoc. See the [pkg.go.dev reference for github.com/ju4n97/catl](https://pkg.go.dev/github.com/ju4n97/catl) for auto-generated API documentation.

```bash
go get github.com/ju4n97/catl@latest
```

```go
import "github.com/ju4n97/catl"
```

## Opening a catalog

Use `catl.Open` to read and validate a catalog from disk:

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/ju4n97/catl"
)

type Policy struct {
	Severity string `json:"severity"`
	Enabled  bool   `json:"enabled"`
}

func main() {
	ctx := context.Background()

	cat, err := catl.Open(ctx, "./compliance-catalog", catl.Options{
		Offline: true, // Forbid network calls; read from vendor or cache only
	})
	if err != nil {
		log.Fatalf("failed to open catalog: %v", err)
	}

	// Resolve an entity by collection and qualified ID
	entity, err := cat.Resolve("policies", "compliance.require-mfa")
	if err != nil {
		log.Fatalf("failed to resolve entity: %v", err)
	}

	// Decode the manifest into your application's struct
	var p Policy
	if err := entity.Unmarshal(&p); err != nil {
		log.Fatalf("manifest decode error: %v", err)
	}

	fmt.Printf("Policy %s: severity=%s enabled=%v\n", entity.QualifiedID, p.Severity, p.Enabled)
}
```

`catl.Open` performs the following steps:

1. Parses and validates `catl.toml`.
2. Computes the catalog tree hash and checks integrity.
3. Validates all manifests against their respective collection JSON Schemas.
4. Returns a `*catl.Catalog` instance that is immutable and safe for concurrent use across goroutines.

## Verifying catalog tree hashes

To verify catalog content integrity or check for drift, compute the deterministic tree hash:

```go
treeHash, err := cat.TreeHash()
if err != nil {
	log.Fatalf("tree hash computation failed: %v", err)
}
fmt.Println("Catalog SHA-256 tree hash:", treeHash)
```

## Reading companion files

For bundle entities, access companion files using standard `io/fs.FS` interfaces through `entity.FS(ctx)`:

```go
package main

import (
	"context"
	"fmt"
	"io/fs"
	"log"

	"github.com/ju4n97/catl"
)

func readRunbook(ctx context.Context, cat *catl.Catalog, qualifiedID string) error {
	entity, err := cat.Resolve("monitors", qualifiedID)
	if err != nil {
		return err
	}

	if !entity.IsBundle() {
		return fmt.Errorf("entity %q is not a bundle", entity.ID)
	}

	// entity.FS returns a read-only io/fs.FS scoped to the bundle directory
	fsys, err := entity.FS(ctx)
	if err != nil {
		return err
	}

	// Read a companion file
	data, err := fs.ReadFile(fsys, "mitigation.md")
	if err != nil {
		return fmt.Errorf("could not read companion file: %w", err)
	}

	fmt.Printf("Runbook:\n%s\n", string(data))
	return nil
}
```

The returned filesystem adheres to standard Go `fs.ValidPath` rules: paths escaping the bundle directory with `..` are rejected, and dot-prefixed files are hidden.

## Managing registries with `OpenRegistry`

When an application manages multiple catalogs concurrently (such as a directory of tenant catalogs), use `catl.OpenRegistry`:

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/ju4n97/catl"
)

func main() {
	ctx := context.Background()

	reg, err := catl.OpenRegistry(ctx, "./registry.d", catl.Options{Offline: true})
	if err != nil {
		log.Fatalf("failed to open registry: %v", err)
	}

	// List discovered catalog namespaces
	for _, name := range reg.Names() {
		cat, _ := reg.Catalog(name)
		fmt.Printf("Tenant: %s (%d collections)\n", cat.Name(), len(cat.Collections()))
	}

	// Query an entity directly within a specific catalog
	compliance, ok := reg.Catalog("compliance")
	if ok {
		ent, err := compliance.Resolve("rules", "compliance.require-mfa")
		if err == nil {
			fmt.Println("Resolved entity path:", ent.ManifestPath)
		}
	}
}
```

## In-memory testing with `OpenFS`

To test applications without touching the local disk, use `catl.OpenFS` with `testing/fstest.MapFS` or Go's standard `embed.FS`:

```go
package main

import (
	"context"
	"embed"
	"io/fs"
	"testing"

	"github.com/ju4n97/catl"
)

//go:embed testdata/catalog/*
var testCatalogFS embed.FS

func TestCatalogIntegration(t *testing.T) {
	ctx := context.Background()

	subFS, err := fs.Sub(testCatalogFS, "testdata/catalog")
	if err != nil {
		t.Fatalf("sub fs error: %v", err)
	}

	cat, err := catl.OpenFS(ctx, subFS, catl.Options{})
	if err != nil {
		t.Fatalf("OpenFS failed: %v", err)
	}

	entity, err := cat.Resolve("rules", "test-catalog.allow-all")
	if err != nil {
		t.Fatalf("Resolve failed: %v", err)
	}

	if entity.ID != "allow-all" {
		t.Errorf("got ID %q, want allow-all", entity.ID)
	}
}
```

## Atomic catalog swapping in servers

Services can reload updated catalogs without restarting the process using Go's standard `sync/atomic`:

```go
package main

import (
	"context"
	"sync/atomic"

	"github.com/ju4n97/catl"
)

type Server struct {
	catalog atomic.Pointer[catl.Catalog]
}

func (s *Server) Reload(ctx context.Context, dir string) error {
	next, err := catl.Open(ctx, dir, catl.Options{Offline: true})
	if err != nil {
		return err // Validation failed; keep existing catalog active
	}

	s.catalog.Store(next)
	return nil
}

func (s *Server) CurrentCatalog() *catl.Catalog {
	return s.catalog.Load()
}
```

## Error handling

Inspect failure reasons using standard `errors.Is`:

```go
if err != nil {
	switch {
	case errors.Is(err, catl.ErrNotFound):
		// The entity, collection, or catalog namespace doesn't exist
	case errors.Is(err, catl.ErrNotQualified):
		// The caller passed a bare ID without a namespace
	case errors.Is(err, catl.ErrLockStale):
		// catl.lock doesn't match catl.toml; needs 'catl update'
	case errors.Is(err, catl.ErrTamperedVendor):
		// Files inside .catl/vendor don't match the tree hash
	case errors.Is(err, catl.ErrRequiresNewer):
		// The catalog requires a newer version of the catl library
	}
}
```

To extract structured line-by-line schema validation failures, inspect `*schema.ValidationError` using `errors.AsType`:

```go
var valErr *catl.ValidationError
if errors.AsType[*catl.ValidationError](err) {
	for _, d := range valErr.Diagnostics {
		log.Printf("%s:%d: [%s] %s\n", d.Path, d.Line, d.Pointer, d.Message)
	}
}
```
