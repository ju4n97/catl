# Installation

`catl` is distributed as a single static binary with no CGO or libc dependencies. Archive packaging, content tree hashing, and JSON Schema validation are implemented natively in Go without shelling out to `tar`.

Prebuilt binaries are available for Linux, macOS, and Windows on x86_64 and arm64.

## System requirements

- **Core operations:** Zero external runtime dependencies. Commands that operate locally, such as `catl check`, `catl list`, `catl resolve`, `catl pack`, and the Go library API, run hermetically in scratch or distroless containers without external utilities.
- **Git dependencies (optional):** If you fetch or update remote Git dependencies using `catl add` or `catl update`, the system `git` CLI (2.30+) must be available in your `PATH`. If `git` is missing, only those remote mutation commands fail; offline validation and inspection remain fully functional.

## Shell script (Linux and macOS)

Download the install script pinned to a release tag, verify its SHA-256 digest, and run it:

```bash
VERSION="latest"
EXPECTED_SHA256="4b227777d4dd1fc61c6f884f48641d02b4d121d3fd328cb08b5531fcacdabf8a"

curl -fsSLO "https://github.com/ju4n97/catl/releases/download/${VERSION}/install.sh"
echo "${EXPECTED_SHA256} install.sh" | sha256sum -c -

bash install.sh --version "${VERSION}"
rm install.sh
```

````

The script installs the binary to `/usr/local/bin/catl`, or `$HOME/.local/bin/catl` when running without root permissions.

## PowerShell (Windows)

Download and verify the Windows installer:

```powershell
$Version = "latest"
$ExpectedHash = "9f2c1a7b8e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b"

Invoke-WebRequest -Uri "https://github.com/ju4n97/catl/releases/download/$Version/install.ps1" -OutFile install.ps1
$ActualHash = (Get-FileHash install.ps1 -Algorithm SHA256).Hash.ToLower()

if ($ActualHash -ne $ExpectedHash) {
    Remove-Item install.ps1
    throw "Checksum mismatch: expected $ExpectedHash, got $ActualHash"
}

& .\install.ps1 -Version $Version
Remove-Item install.ps1
```

## Go install

If you have Go 1.27+ installed, build and install the binary directly from source:

```bash
go install github.com/ju4n97/catl/cmd/catl@latest
```

Ensure `$GOPATH/bin` or `$HOME/go/bin` is present in your `PATH`.

## Container image

Run `catl` in CI pipelines or automated workflows using the official container image:

```bash
# Run with a pinned release tag
docker run --rm -v "$(pwd):/catalog" ghcr.io/ju4n97/catl:latest -C /catalog check

# Or pin directly by digest
docker run --rm -v "$(pwd):/catalog" \
  ghcr.io/ju4n97/catl@sha256:77d1a3c9e0b4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0 \
  -C /catalog check
```

The container image includes the system `git` client so CI jobs can run `catl update` or fetch remote dependencies without additional setup.

## Verifying the binary

Check that the binary is installed correctly and verify its reported version:

```bash
catl version
```

Output:

```text
catl <version>
```
````
